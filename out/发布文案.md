## 简介

写给零基础新手（高中毕业生也能看懂）的 GitHub 教程。
不讲空话，直接对着 GitHub 界面，一个按钮一个按钮地讲：它在哪、点了会发生什么、背后的原理是什么、什么时候该用。

✅ 界面和真实 GitHub 一样，看完就能上手
✅ 每章都有原理动画：commit、分支、合并、冲突一看就懂
✅ 命令演示用 Windows PowerShell，跟着敲就行
✅ 中英双语字幕，结尾附命令和按钮速查表

📌 开始前只需要：① 安装 Git（git-scm.com） ② 注册并登录 GitHub 账号
